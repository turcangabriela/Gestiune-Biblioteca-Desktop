# Booklated Library Management System

## Descrierea proiectului

Booklated Library Management System este un proiect care prezintă un prototip interactiv al unui sistem de gestionare a unei biblioteci.

Scopul acestuia este de a ilustra modul în care pot fi gestionate informațiile despre cărți și membri, precum și operațiile de împrumut și returnare a cărților.

## Funcționalități principale

- Autentificarea bibliotecarului
- Înregistrarea membrilor
- Adăugarea și vizualizarea cărților
- Gestionarea cărților împrumutate
- Evidența returnărilor
- Consultarea istoricului cărților

## Arhitectura sistemului

Sistemul este organizat conceptual în trei straturi:

1. **Presentation Layer** – interfața grafică prin care utilizatorii interacționează cu aplicația.
2. **Business Logic Layer** – gestionează operațiile și regulile aplicației.
3. **Data Access Layer** – se ocupă de accesul și gestionarea datelor.

Descrierea detaliată este disponibilă în folderul `docs`.
